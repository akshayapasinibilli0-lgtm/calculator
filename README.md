# 🧮 Minimalist iOS-Style Dark Calculator

A modern, responsive dark-mode calculator inspired by the iOS calculator interface, built using vanilla HTML, CSS Grid, and JavaScript.

## ✨ Features

- **iOS-Inspired Aesthetic**: Sleek dark theme with authentic button colors, subtle shadows, and interactive click animations.
- **CSS Grid Layout**: Responsive 4x5 button matrix with an expanding zero button.
- **Robust Math Engine**:
  - Basic arithmetic (+, −, ×, ÷)
  - Decimal precision and duplicate prevention
  - Operation chaining (e.g. `12 + 8 × 2`)
  - Percentage calculation (%)
  - Division by zero protection (`Error`)
  - Backspace (DEL) and All Clear (AC)
- **Formatted Display**: Numbers are formatted with commas for readability (e.g., `1,250,000`).
- **Keyboard Support**: Full numpad and keyboard shortcuts (Enter, Backspace, Escape, operators).

## 🚀 Getting Started

No build tools or installations are required!

1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/calculator.git
   ```
2. Navigate into the folder:
   ```bash
   cd calculator
   ```
3. Open `index.html` in any web browser.
